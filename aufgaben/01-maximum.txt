Größte Zahl im Array
Schreibe eine Methode max, die ein int-Array erhält und die größte darin enthaltene Zahl zurückgibt.
Du darfst annehmen, dass das Array mindestens ein Element enthält.
===CODE===
public static int max(int[] a) {
    int max = a[0];
    for (int i = 1; i < a.length; i++) {
        if (a[i] > max) {
            max = a[i];
        }
    }
    return max;
}
===FALSCH===
