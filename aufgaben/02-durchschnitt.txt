Durchschnitt berechnen
Schreibe eine Methode durchschnitt, die den Durchschnitt (Mittelwert) aller Werte eines int-Arrays als double zurückgibt.
Beispiel: {1, 2} ergibt 1.5
===CODE===
public static double durchschnitt(int[] werte) {
    int summe = 0;
    for (int i = 0; i < werte.length; i++) {
        summe += werte[i];
    }
    return (double) summe / werte.length;
}
===FALSCH===
