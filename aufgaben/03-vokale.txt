Vokale zählen
Schreibe eine Methode zaehleVokale, die zählt, wie viele Vokale (a, e, i, o, u – nur Kleinbuchstaben) in einem String vorkommen.
Beispiel: "informatik" ergibt 4
===CODE===
public static int zaehleVokale(String text) {
    int anzahl = 0;
    for (int i = 0; i < text.length(); i++) {
        char c = text.charAt(i);
        if ("aeiou".indexOf(c) >= 0) {
            anzahl++;
        }
    }
    return anzahl;
}
