Fakultät (rekursiv)
Schreibe eine rekursive Methode fakultaet, die n! = 1 · 2 · … · n berechnet. Es gilt 0! = 1.
Nutze long als Rückgabetyp, weil die Werte sehr schnell sehr groß werden.
===CODE===
public static long fakultaet(int n) {
    if (n <= 1) {
        return 1;
    }
    return n * fakultaet(n - 1);
}
