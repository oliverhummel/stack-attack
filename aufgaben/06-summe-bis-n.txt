Summe von 1 bis n
Schreibe eine Methode summeBis, die die Summe aller ganzen Zahlen von 1 bis n berechnet und zurückgibt.
Beispiel: summeBis(4) ergibt 1 + 2 + 3 + 4 = 10
===CODE===
public static int summeBis(int n) {
    int summe = 0;
    for (int i = 1; i <= n; i++) {
        summe += i;
    }
    return summe;
}
