Gerade Zahlen zählen
Schreibe eine Methode zaehleGerade, die zählt, wie viele gerade Zahlen in einem int-Array stehen.
Nutze dafür die for-each-Schleife.
Beispiel: {3, 8, 10, 7} ergibt 2
===CODE===
public static int zaehleGerade(int[] zahlen) {
    int anzahl = 0;
    for (int z : zahlen) {
        if (z % 2 == 0) {
            anzahl++;
        }
    }
    return anzahl;
}
