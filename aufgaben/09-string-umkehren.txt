String umkehren
Schreibe eine Methode umkehren, die einen String rückwärts zurückgibt.
Beispiel: "java" ergibt "avaj"
===CODE===
public static String umkehren(String text) {
    String ergebnis = "";
    for (int i = text.length() - 1; i >= 0; i--) {
        ergebnis += text.charAt(i);
    }
    return ergebnis;
}
