Primzahl prüfen
Schreibe eine Methode istPrimzahl, die true zurückgibt, wenn n eine Primzahl ist.
Tipp: Es reicht, Teiler t zu prüfen, solange t * t <= n gilt.
===CODE===
public static boolean istPrimzahl(int n) {
    if (n < 2) {
        return false;
    }
    for (int t = 2; t * t <= n; t++) {
        if (n % t == 0) {
            return false;
        }
    }
    return true;
}
